# 设计图集

`design/core/` 的图示视图：静态结构、状态机与假想运行时时序。

- 图不是设计内容：每张图只画正文已定的东西，节点、边、状态名与正文用词一致。
- 正文改了图随之改；图上出现正文没有的东西即图错。
- 图的用途是把链路摆在眼前，逐条检查“这一步谁做、写哪条记录、崩了怎么办”。

图一律 Mermaid。每张图有编号 `Dx.y`、对照的正文章节、读法（假想运行时）、核出（画图时发现并已并入正文的缺口，或“无”）。正文相应章节以 `> 图：` 行反向指向这里。

章节号 `§N.M` 指 `design/core/` 下前缀为 N 的文件中的第 M 个二级标题。
