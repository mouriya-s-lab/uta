# UTA 需求追踪矩阵

本文件把 `local://w1-trace-matrix.md` 的 273 个稳定行逐一映射到冻结决策、规范章节、类型契约和验证入口。ID 家族含义如下：`AX-*` 是 axioms，`DC-*` 是 detail constraints，`INV-*` 是 Wave-1 observed invariants，`OQ-*`/`OQC-*` 是 open questions，`SF-*` 是 surfaces，`ST-*` 是 stores，`NF-*` 是 non-functional requirements。原始 ID、Source、Requirement 和 Category 保持不变。

`Status` 语义：`resolved` 表示 D1–D13 或 Residual rulings R1–R7 与现有规范/类型已经作出单一、可实现的裁决；`out-of-scope` 表示该行描述的旧行为已由 register 明确替换，或落在 D13 范围外；`blocked(evidence: …)` 表示 08 中要求的 runtime/外部证据尚未取得。`blocked` 行就是本矩阵的 open rows；它们不会被静默当作 resolved。

`Resolved by` 中的 `D1`–`D13` 或 `R1`–`R7` 是 `00-decision-register.md` 的精确决策编号，随后是已核实存在的 spec heading 和/或 `spec/types/` 的 owning module/type。`Verification scenario` 只引用 `08-verification.md` 已出现的 `CR-*`、`H-*`、`M-*`、`P-*`、fixture 名或 gate；它是能够证伪该映射的入口，不表示该 gate 已经通过。更新矩阵时保留 ID，先核对 register，再核对目标 heading/type 和 scenario 的字面名称；改变决策或证据状态时直接更新该行，并同步 Open rows 与计数，禁止新增平行 ID、别名或“暂时 resolved”。
